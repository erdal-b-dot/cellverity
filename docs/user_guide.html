1. What does the program do?

It measures per-cell CTCF (corrected total cell fluorescence) in immunocytochemistry (ICC) fluorescence images:

CTCF = Integrated density − (Cell area × Mean background) (McCloy et al., 2014, Cell Cycle 13:1400–1412)

It automates the manual ImageJ workflow:

Manually in ImageJ In this program
Calibrate with Set Scale The scale bar and the value printed under it (20 µm, 50 µm) are read automatically
Trace every cell with the polygon tool Cells are segmented from FITC; touching cells are separated using DAPI nuclei
Draw and measure 3 background regions 3 boxes are placed automatically away from cells (movable, or add your own)
Measure → copy to Excel → formula Table, Excel, group summary, plots and statistics in one click

Measurements are identical to ImageJ/Fiji. For the same cell boundaries, Area, Mean, StdDev, Min, Max, IntDen and RawIntDen are the same as Fiji's (largest difference < 0.00001 %). You can check this yourself from within the program: Fiji ▸ Verify with Fiji (Section 11).

Your images are never sent anywhere; the program works offline.

Language: the interface follows your computer's language (Turkish or English). Change it under View ▸ Language / Dil (takes effect after restart). Excel output is always in English.

3. Image requirements

However good the program is, the validity of the measurement depends on the image.

Required: - Raw, single-channel images. The FITC image saved directly by the microscope software (cellSens etc.). Images that went through Photoshop, had brightness/contrast adjusted, or were merged cannot be used for CTCF — the program detects these and warns you. - All compared images acquired with identical settings: same objective, exposure time, gain, lamp power, white balance. Fluorescence signal scales with exposure: a cell in a 1 s image looks ~2× brighter than in a 0.5 s image. Turn off auto-exposure in cellSens. The program reads the exposure time from the image (EXIF), shows it in the panel and in Excel, and warns when exposures are mixed. - Same objective. Do not compare 20× with 40× images — the program warns if objectives are mixed. - No saturated pixels. The number of saturated pixels is reported for every cell ("Saturated px" column).

Recommended: - The DAPI image of the same field. Essential for separating touching cells correctly (Warnings). - Calibration: the image needs a scale bar (cellSens style: white box in the lower right corner) or pixel-size information in the file (cellSens raw TIFF, OME-TIFF, ImageJ TIFF). Without either, you enter the pixel size manually (6.2). - TIFF is better than JPEG (JPEG is lossy). Use the same format for all FITC images of a study (DAPI is only used to separate cells and may be JPG; TIFF FITC + JPG DAPI pairing is supported). - Supported files: JPG, PNG, TIFF (8/16-bit, RGB or single channel). Vendor formats (.czi, .nd2, .lif, .vsi) are not supported yet; save them as TIFF in Fiji (the pixel size is kept).

Tested equipment: Olympus BX43 fluorescence microscope, Olympus DP74 colour camera, cellSens Entry software. On this camera FITC appears yellow-green and DAPI cyan. FITC is measured on the green (G) channel; FITC and DAPI are told apart by the blue/red ratio of the brightest pixels. Other cameras/software should work for measurement; if the scale-bar label cannot be read, the program warns you and asks for the value (Section 6.2).

4. Quick start (5 minutes)

Example images to try: the examples/ folder in the repository (two FITC + DAPI pairs with expected results, CC BY 4.0).

  1. Open the program.
  2. In Finder/Explorer, select the FITC and DAPI files together and drag them onto the window. The program tells which one is DAPI by its colour.
  3. Check the right panel: Calibration (e.g. 0.1449 µm/pixel, 20 µm, read from label), Objective, Cell count, the green "Cell separation: DAPI nuclei" box.
  4. Select all cells (or click the cells to measure — they turn yellow). The Cells tab below shows CTCF.
  5. In the right panel enter Group / condition (e.g. Control) and Experiment / replicate (e.g. 1) → ➕ Add to results table (⌘↩ / Ctrl+Enter).
  6. Next image: close with ⌘W, drag the next pair, change the group, add.
  7. When done: Save to Excel (⌘E) and Plot… (⌘G).

With many images, use Batch-measure folder (⌘B) instead of steps 4–6 (Section 8).

6. Measuring a single image — step by step

6.1 Opening images

  • Drag and drop (easiest): drag FITC + DAPI together.
  • Open FITC… (⌘O) and Open DAPI… (⌘D).
  • If you use the wrong button (e.g. a blue file with "Open FITC"), the program asks: "… looks like a DAPI image, open it as DAPI?"
  • Opening a new FITC removes the previous field's DAPI (another field's nuclei would separate cells wrongly). Open the new field's DAPI too.
  • Close images (⌘W): clears the window; collected results are kept.

6.2 Checking the calibration

The Calibration line in the right panel also tells the source: - read from label — the value under the scale bar (20 µm, 50 µm) was read. ✅ - entered manually — the value you typed into the Scale bar box. - label NOT READ, assumed — a red warning appears; type the value shown in the image into the Scale bar box. - from file metadata (OME / Olympus SIS / ImageJ) — the image has no scale bar; the pixel size was read from the file. cellSens raw TIFF files are like this (no bar burned in, pixel size stored in the file). ✅ - entered manually (µm/pixel) — Edit ▸ Enter calibration manually: enter the pixel size directly or from the objective + camera pixel size (camera pixel ÷ magnification; DP74: 5.86 µm).

Order of precedence: manually entered value → scale bar in the image → file metadata. If both a bar and metadata exist and differ by more than 3 %, a red warning appears (the image may have been resized or the bar misread).

If no scale is found at all (no bar, no metadata) the program asks for the calibration in a dialog. With Measure in pixels, areas are in pixels² and the cell/nucleus size filters work in pixels — cells may be fragmented; use it only to compare images acquired with identical settings among themselves. In batch mode, uncalibrated images are flagged in the results and statistics.

⚠️ A wrong scale value makes area and IntDen wrong several-fold (e.g. 20 µm instead of 50 µm: 6.25×). Glance at the calibration line for every new image.

Known values for DP74 + cellSens: 20 µm = 138 px → 0.1449 µm/px (40×); 50 µm = 172 px → 0.2907 µm/px (20×).

6.3 Cell-separation indicator

Indicator Meaning What to do
🟢 DAPI nuclei Touching cells were separated using nuclei —
🟡 Shape only (no touching cells) No DAPI, but none needed —
🔴 Shape only — N touching cell pairs Touching cells separated by shape only (~5% error) Open the DAPI of the same field

6.4 Selecting cells

  • Click a cell → it turns yellow and is measured; click again → deselected.
  • Select all cells / Clear selection.
  • Do not measure cells cut off at the image border (their area is incomplete).

6.4.1 Quality control and documented exclusion

  • Automatic quality control (QC) — Exclude cells failing quality control in the right panel (on by default). These cells are outlined in orange and are not selected by Select all cells:
  • cells with saturated pixels (CTCF underestimated),
  • cells with no nucleus or several nuclei (usually a segmentation error → Split/Merge),
  • partial nucleus: nuclear area inside the cell < 30% of the image median (a cut-off or wrongly separated cell fragment),
  • pyknotic nucleus: nuclear area < 50% of the median and DAPI intensity > 1.5× the median (a heuristic criterion for apoptotic nuclei; check visually).
  • Manual exclusion — right-click a cell ▸ choose a reason: apoptotic / pyknotic, mitotic, overlapping / not separable, out of focus, debris / not a cell, other. The cell is outlined in red. To undo: right-click ▸ Remove exclusion (or click to select the cell).
  • To measure a QC-flagged cell anyway, click to select it; its flag stays in the QC_flags column.
  • Every excluded cell is written with its reason to the Excluded_cells sheet in Excel, with counts in Exclusion_summary — report as "n cells were excluded (x saturated, y apoptotic …)".
  • Recommended approach to cell selection and sampling: predefined criteria, systematic field selection, exclusions made blind to treatment group, ≥ 3 independent experiments.

6.5 Background

  • Automatic (default): 3 boxes (50×50 pixels) ≥ 40 pixels away from cells, free of signal/debris, as close to the cells as possible. Size and number are set in the right panel.
  • Moving boxes: hover over a box (hand cursor), press and drag. It is re-measured when released. Moving an automatic box switches to Manual; the other boxes stay in place.
  • Manual: click an empty area → a box is added; click a box → it is removed. Clear manual boxes.
  • A box overlapping a cell is not accepted (it moves back).
  • Per-box values: Background boxes tab below.

ℹ️ If the background is 0, the camera/cellSens clipped the dark background to zero; CTCF = IntDen. Comparisons are valid if all images were acquired with the same settings.

6.5.1 Nucleus / cytoplasm (N/C ratio)

If a DAPI image is open, the program measures the nucleus and the cytoplasm of every cell separately. Nothing else is needed; the results appear in the N/C column. Translocation of a protein into the nucleus (e.g. nuclear accumulation of p53 on activation) is a direct read-out of pathway activity. Whole-cell CTCF does not show it; the N/C ratio does.

  • Nucleus = DAPI mask. Cytoplasm = cell − nucleus.
  • Edge ring (right panel ▸ Nucleus / cytoplasm (N/C), default 0.5 µm): FITC and DAPI are acquired with separate exposures, so the nuclear edge can be shifted by a few pixels. The nucleus is shrunk by this distance and the cytoplasm starts this far from the nucleus. The ring belongs to neither compartment. 0 = no ring.
  • N/C ratio = (nuclear mean − background) / (cytoplasmic mean − background). It is the ratio of background-corrected mean intensities and does not depend on cell size. Above 1, the signal is more concentrated in the nucleus.
  • Nuclear fraction of signal (Nuc_fraction) = nuclear CTCF / (nuclear + cytoplasmic CTCF).
  • Thin cytoplasm: if the measured cytoplasm is smaller than 20 % of the cell area, the ratio comes from few pixels and is unreliable. The cell is flagged (N/C QC column: thin_cytoplasm) and left out of the N/C analysis only. Its whole-cell CTCF remains valid. The statistics text states how many cells were left out.
  • In plots and statistics, NC_ratio, Nuc_fraction, Nuc_CTCF and Cyto_CTCF can be chosen as the Variable.

⚠️ On a widefield microscope, out-of-focus cytoplasm above and below the nucleus adds to the nuclear value, so the N/C ratio is biased toward 1. Compare conditions (control vs treatment), not absolute values. Confocal images are much less affected.

ℹ️ Because it is a ratio of two measurements, the N/C ratio is largely independent of exposure time (provided the camera is linear). Acquiring the compared images with identical settings is still the safest approach.

6.6 Adding to the results table

  • Group / condition: e.g. Control, Drug 10 µM 24 h. Plots and statistics group by this label.
  • Experiment / replicate: independent experiment (biological replicate): 1, 2, 3… Needed for statistics on experiment means (Section 10).
  • ➕ Add to results table (⌘↩). Re-adding the same image replaces the earlier entry (it is not counted twice).

7. Editing cell boundaries

Automatic boundaries are good in most images; dense clusters, debris or dim cells may need corrections. Toolbar 2 ▸ Boundary editing:

  • Edits are written to the Manual_edits column in Excel (e.g. merge 1+2; split 1).
  • Changing the scale value re-analyses the image and resets the edits (a warning appears below). Calibrate first, then edit.

  Exp_1/
    Control/      ← FITC + DAPI images
    Treatment1/

  Exp_2/

  • Group = name of the folder containing the image; Experiment = the folder above it.
  • If you select a single experiment folder (e.g. Exp_1), its name becomes the experiment name.
  • Both can be edited in the table before measuring.

8.2 FITC–DAPI pairing

Each FITC is paired with the DAPI, among those within ±3 file numbers in the same folder, whose nuclei actually overlap the cells. Overlap is a chance-corrected score (1 = all nuclei inside cells, 0 = no better than random placement); ≥ 0.5 is required. A raw fraction would mislead: in a crowded field where cells cover half the image, a DAPI from another field still overlaps ~50%. Consecutive numbers do not always mean the same field — the program checks the images themselves.

Status Meaning
🟢 ready Pair found (percentage in the Overlap column; the Exposure column shows the FITC exposure time — a red warning appears below if exposures differ within the folder)
🟠 no DAPI No matching DAPI; cells will be separated by shape only
⚪ skipped: no camera information Merged or re-saved image
⚪ skipped: processed image Saved by Photoshop etc.
⚪ skipped: could not tell FITC from DAPI Ambiguous colour (e.g. merged)
⚪ skipped: unpaired DAPI A DAPI that belongs to no FITC

8.3 Measurement

  • Ticked rows are measured; untick those you do not want.
  • In each image: all cells + automatic background (box size/number from the right panel).
  • With Exclude cells failing quality control ticked, QC-flagged cells are not measured; together with border cells they are written with their reason to Excluded_cells (border, saturated, no_nucleus, partial_nucleus, multinucleate, pyknotic).
  • Cells touching the image border are excluded by default.
  • The Selection column in Excel records manual click or batch: all cells, edge excluded.
  • After batch measurement, check suspicious images (especially dense clusters): in the Collected results tab, hover over a row to preview the cell; click the row to open that image with its DAPI — the cells recorded in the table are selected and the clicked cell is centred. Edit boundaries (Section 7) or Verify with Fiji, then Add to results table to replace that image's earlier rows.

Setting Options

Variable CTCF · CTCF_per_Area · Mean · IntDen · Area

Tests: 2 groups → Welch's t-test + Mann–Whitney U. 3+ groups → one-way ANOVA + Kruskal–Wallis + Dunnett (or Tukey).

10.1 Important: the statistical unit (pseudoreplication)

Cells from the same experiment are not independent. Counting every cell as a replicate makes p values look smaller than they are (one of the most common issues flagged by reviewers). Example (simulated data, 3 experiments × 3 images × 6 cells):

Unit n Dunnett p (treatment vs control)
Cell 54 0.069
Experiment mean 3 0.62

Recommendation: in publications, run statistics on means of independent experiments (at least 3); individual cells can still be shown as points in the plot. The program warns when you test at the cell level.

Dunnett p values are computed by numerical integration; the program uses a fixed seed, so the same data always give the same p.

Save: plot as PNG (600 dpi), PDF, SVG; statistics as .txt.

10.2 Protein panel (several proteins, pathway level)

To see a drug's effect on a pathway, the proteins do not need to be measured in the same cell. In the same experiment, protein X can be measured in one set of wells and protein Y in others, each with a single channel.

  1. When adding each image, type the protein in the Protein / target field of the right panel (e.g. p53). In batch mode, a Protein/Experiment_1/Control/… folder layout gives the protein from the folder name; otherwise one name for the whole folder can be entered in the dialog.

  2. Results ▸ Protein panel… (⌘⇧G).

  3. Different proteins are measured with different antibodies, so raw CTCF values cannot be compared between proteins. Each protein is normalised to its own control in the same experiment (fold change; from experiment means).

  4. Plot: large dot = geometric-mean fold change, line = 95 % confidence interval, small dots = independent experiments, dashed line = control (1).
  5. Test: one-sample t-test of log₂(fold change) = 0 (equivalent to GraphPad's ratio paired t test), Holm correction across groups within each protein. n = independent experiments (at least 3 recommended).
  6. An experiment without a control group is skipped and reported. Excel gets Protein_panel (summary) and Protein_panel_experiments (fold change per experiment) sheets.
  7. With several proteins, the Plots and statistics dialog asks for a protein; group comparisons are done separately for each protein.

ℹ️ This view shows how the proteins change together at the pathway level (e.g. does MDM2 rise when p53 rises with the drug?). It does not show the relationship within the same cell; that needs double staining.

11. Fiji bridge and method validation

Fiji menu:

11.1 Verify with Fiji (⌘⇧F)

Has Fiji's own Measure engine measure the selected cells, the background boxes and (with DAPI) the nuclear/cytoplasmic compartments in the background. The compartments are exported as label images, Fiji creates its own selections (Threshold → Create Selection) and the N/C ratio is recalculated from Fiji's values. No Fiji window opens (~5 seconds); the results are shown side by side with the program's. When the image is added to the results table, the outcome is written to the Fiji_check column (e.g. OK (1.54p99, max diff 3.3e-07 %)). Changing the selection, boxes or boundaries invalidates the earlier check.

11.2 Open in Fiji

Opens Fiji with its interface: image, scale, all ROIs in the ROI Manager (cells, background boxes and, with DAPI, the Nuc_n / Cyto_n compartments), Measure results (ROI name on every row). Files: Documents/CellVerity/Fiji/<image name>/.

11.3 Compare with manually traced ROIs (method validation)

To quantify how close the automatic boundaries are to manual tracing (recommended for papers):

  1. In Fiji, open the FITC image. Trace a cell with the Polygon or Freehand tool → T (add to ROI Manager). Repeat for all cells.
  2. ROI Manager ▸ More » ▸ Save… → manual_RoiSet_<image>.zip
  3. In the program, open the same image (and its DAPI) → Fiji ▸ Compare with ROIs traced manually… → choose the zip.
  4. Each manual ROI is matched to the automatic cell it overlaps most: area difference, CTCF difference, Dice and IoU (boundary overlap; 1 = perfect).
  5. ➕ Add to validation table. Repeat for 3–5 images (separate + touching cells, different conditions).
  6. Fiji ▸ Method validation table and Bland–Altman…: scatter plot + Bland–Altman (percentage difference), mean difference (bias), 95% limits of agreement, Pearson r, Lin's CCC, Dice.

Recommendation: ≥ 30 cells, ≥ 3 images. Optionally re-trace the same cells a few hours later (intra-observer variability): if the automatic–manual difference is not larger than the manual–manual difference, the method is at least as reliable as manual measurement.

15. Technical details

Measurement definitions (same as ImageJ): - Area = number of pixels × (µm/pixel)² - IntDen = Area × Mean (calibrated units); RawIntDen = sum of pixel values - StdDev = sample standard deviation (n − 1) - ROI rule: a pixel belongs to the ROI if its centre lies inside the polygon - CTCF = IntDen − Area × BG_Mean; CTCF_per_Area = Mean − BG_Mean

Calibration: the length of the cellSens scale bar (white box, lower right) is measured in pixels; the bar is located first (a thin black line with white above and below), the box is measured from the bar's white margin, and the number below it is read with digit templates. Tested on 3,534 fluorescence images (author's archive 3,233 + development set 301; two cellSens box styles): all read correctly. Objective = camera pixel size (DP74: 5.86 µm) ÷ µm/pixel.

Cell segmentation: FITC (G channel) Gaussian smoothing → Li threshold → closing, hole filling, small-object removal (< 50 µm²) → watershed seeded with DAPI nuclei (distance transform if no DAPI).

Nucleus detection (Nucleus_method): | Method | Version | Description | |---|---|---| | otsu | v1.0.0 | Otsu threshold (also includes the dim DAPI halo) | | bright_core | early v2 | Upper threshold of 3-class Otsu (misses dim nuclei) | | local | v2.0.0 default | Otsu mask → watershed from smoothed DAPI maxima → each nucleus trimmed at half of its own peak intensity |

Validation results: - Identical to Fiji 1.54p for the same ROIs: Area/Mean/StdDev/Min/Max/IntDen/RawIntDen (5 ROIs in a 40× image; 54 ROIs in a 20× image with non-zero background; largest difference < 0.00001 %). - Manual tracing (1 image, 2 touching cells — preliminary): Dice 0.943 / 0.938; CTCF difference +2.3 % / +3.7 %. - Dense clusters at 20×: 47 nuclei, 51 cells detected.

Program files: core.py (measurement), batch.py (batch), report.py (Excel, plots, statistics), fiji.py (Fiji bridge), desktop.py (interface), i18n.py + locales/ (languages), tests/test_core.py (validation tests).
